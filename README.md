## 📖 About

JoyToKey is a lightweight input mapping utility for Windows originally developed by JTK Software. It reads the state of any connected gamepad, joystick or arcade stick and translates each button, trigger, hat switch or analog axis into keyboard strokes, mouse movement, mouse clicks or wheel events. Profiles can be saved per application, so a single controller setup can behave differently in an emulator, a retro platformer or a media player. The 2026 build ships refreshed controller detection, cleaner profile switching and updated compatibility with newer Windows 11 input stacks.

If you came looking for a JoyToKey download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** retro emulator players · arcade stick owners · flight and racing sim tinkerers · accessibility users remapping input · HTPC and couch gaming setups · streamers binding macros to a pad · anyone with a controller and no native gamepad support.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Controller not detected | Reconnect the pad, then reopen JoyToKey so it re-scans input devices. |
| Mapped buttons do nothing in game | Confirm the game window has focus and that the correct profile is active. |
| Cursor drifts when stick is centered | Increase the dead zone for that axis in the profile settings. |
| Two programs react to the same press | Give each program its own profile instead of sharing one global mapping. |
| Profile does not load on launch | Check the target executable path in the profile and re-associate it. |
| High CPU use while idle | Lower the polling rate or disable unused controllers in settings. |
